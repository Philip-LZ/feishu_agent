# XiaoPaw 面试课程路线

课程先建立实现知识，再训练面试表达。每课只解决一个主题，并要求能在源码中找到证据。

| 阶段 | 课程 | 学完应能做到 |
| --- | --- | --- |
| 1 | 系统骨架与请求链路 | 画出一次请求的完整路径，区分确定性控制与 Agent 决策。 |
| 2 | `routing_key`、队列与并发 | 解释同会话保序、跨会话并行、背压和 worker 生命周期。 |
| 3 | Session、上下文与记忆 | 区分业务历史、LLM 上下文、长期记忆及其持久化位置。 |
| 4 | Main Crew、Skill 与 Sub-Crew | 解释渐进式能力披露、两层 Agent 分工和 MCP 执行边界。 |
| 5 | Hook 与安全策略 | 跟踪一次允许或拒绝事件，说明 fail-open / fail-closed 取舍。 |
| 6 | 可观测性 | 解释日志、指标、trace 如何关联，以及敏感数据风险。 |
| 7 | 测试与可靠性 | 选择单元、集成、E2E 测试，并识别文档与运行事实的差异。 |
| 8 | 项目评价与简历表达 | 诚实说明贡献、局限、改进方向和可验证成果。 |
| 9 | 模拟面试 | 在主问题、连续追问和现场改码中综合运用前八课。 |

## 每课固定节奏

```text
概念模型 → 真实源码路径 → 实现取舍 → 小练习 → 课后回忆
```

模拟面试只在核心课程完成后进行，不用面试压力代替知识学习。
